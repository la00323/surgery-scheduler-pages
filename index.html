手術排程 Surgery Scheduler

手術排程是一套供醫師個人使用的手術行程管理工具，在本機電腦上執行，不對外開放註冊或使用。

經使用者本人授權後，本工具會把手術行程（日期、時段、術式、側別、醫院、狀態）單向寫入使用者自己 Google 帳號中的一本專用行事曆，並只管理由本工具建立的事件。

Surgery Scheduler is a personal, self-hosted tool for managing a single physician's surgical schedule. With the user's own authorization, it writes events one-way into a dedicated calendar in the user's own Google account and manages only the events it created.
